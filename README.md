# Minecraft Skin Viewer

Просмотрщик скинов Minecraft в 3D прямо в браузере. Загрузите свой PNG-скин
перетаскиванием — и сразу увидите персонажа в объёме с анимациями. Без
фреймворков и сборки: чистый HTML + CSS + JavaScript и [Three.js](https://threejs.org/)
с CDN. Оформление — в стиле тёмной неоновой аркады.

## Возможности

- **Загрузка скина** — drag-and-drop в любое место сцены или кнопка выбора файла.
  Текстура применяется мгновенно, без перезагрузки страницы.
- **3D-модель из примитивов** — голова, тело, две руки и две ноги собраны из
  `BoxGeometry`. UV-координаты разложены точно по раскладке скина Minecraft.
- **Два формата скинов** — современный `64×64` и классический `64×32`
  (у классического левые конечности зеркалятся с правых). Формат определяется
  автоматически. HD-скины (`128×128` и крупнее) тоже мапятся корректно.
- **Слои оверлея** — отдельные переключатели для шапки (hat) и куртки/рукавов/
  штанин (jacket).
- **7 анимаций** с плавными переходами между позами:
  - `Idle` — лёгкое «дыхание» (колебание масштаба тела по Y)
  - `Walk` — попеременный мах руками и ногами
  - `Run` — ускоренная ходьба с наклоном корпуса вперёд
  - `Wave` — поднятая правая рука машет
  - `Jump` — подпрыгивание с приподнятыми руками
  - `Dance` — раскачка корпуса, руки вверх, повороты
  - `Sneak` — наклон вперёд, присед и медленный шаг
- **Управление камерой** — `OrbitControls`: ЛКМ — вращение, колесо — зум,
  ПКМ — панорама. Кнопки авто-вращения и сброса вида.
- **Неоновое оформление** — фон `#0a0a0f`, акценты cyan `#00f5ff` и lime `#39ff14`,
  шрифт «Press Start 2P», стеклянные карточки (glassmorphism), сканлайны и
  пиксельная сетка поверх канваса, неоновая сетка-пол (`GridHelper`),
  мягкий ambient + directional свет и cyan/lime point-light для контурной подсветки.
- **Счётчик FPS** в углу.
- **Адаптивность** — на широком экране панель управления справа, на узком
  сворачивается в нижнюю «шторку».

## Запуск

Проект использует ES-модули, поэтому его нужно открывать через локальный
веб-сервер (браузеры блокируют загрузку модулей по `file://`).

Любой из вариантов:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve

# либо расширение Live Server в VS Code
```

Затем откройте в браузере `http://localhost:8000` (или порт вашего сервера).
При старте автоматически загружается дефолтный скин в стиле Steve, так что
сцена никогда не бывает пустой.

> Нужен доступ в интернет: Three.js и шрифт подгружаются с CDN.

## Использование

1. Перетащите PNG-скин на сцену или нажмите на зону загрузки и выберите файл.
2. Переключайте анимации кнопками в панели.
3. Включайте/выключайте слои **HAT** и **JACKET**.
4. Вращайте камеру мышью; кнопки **AUTO-ROTATE** и **RESET VIEW** — для удобства.

## Поддерживаемые форматы

| Формат      | Размер  | Левые рука/нога           | Слои оверлея          |
|-------------|---------|---------------------------|-----------------------|
| Современный | `64×64` | собственные текстуры      | шапка + тело/руки/ноги|
| Классический| `64×32` | зеркало правых конечностей| только шапка          |
