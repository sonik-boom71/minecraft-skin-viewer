# Minecraft Skin Viewer

Просмотрщик, редактор и аниматор скинов Minecraft в 3D прямо в браузере.
Загрузите свой PNG-скин перетаскиванием — и сразу увидите персонажа в объёме,
покрутите камеру, включите анимации, перекрасьте текстуру в пиксельном редакторе
и сохраните результат. Без фреймворков и сборки: чистый HTML + CSS + JavaScript
и [Three.js](https://threejs.org/) с CDN, разбитый на ES-модули. Работает офлайн
как PWA. Оформление — в стиле тёмной неоновой аркады.

## Возможности

### Просмотр и 3D-модель

- **3D-модель из примитивов** — голова, тело, две руки и две ноги собраны из
  `BoxGeometry`; UV-координаты разложены точно по раскладке скина Minecraft.
- **Два формата скинов** — современный `64×64` и классический `64×32`
  (у классического левые конечности зеркалятся с правых). Формат определяется
  автоматически; HD-скины (`128×128` и крупнее) мапятся корректно.
- **Слои оверлея** — отдельные переключатели для шапки (hat) и второго слоя
  куртки/рукавов/штанин (jacket).
- **Управление камерой** — `OrbitControls`: ЛКМ — вращение, колесо — зум,
  ПКМ — панорама; кнопки авто-вращения и сброса вида.

### Визуализация

- **Окружения** — несколько неоновых сцен с разным фоном и настроением.
- **Время суток** — плавный день-ночь цикл с меняющимся освещением;
  можно зафиксировать момент или включить авто-смену.
- **Туман** с регулировкой плотности для ощущения глубины.
- **Bloom / постобработка** — свечение через `EffectComposer` +
  `UnrealBloomPass` с настройкой силы.
- **Мягкая тень** под моделью, которая реагирует на прыжки и позы.

### Работа со скинами

- **Загрузка скина** — drag-and-drop в любое место сцены или кнопка выбора файла;
  текстура применяется мгновенно.
- **Поиск по нику** — скин любого игрока подгружается с `minotar.net`
  (фолбэк — `mc-heads.net`).
- **Кураторские коллекции** — Famous, Stars, Builders, Classic — известные
  игроки в один клик.
- **Случайный скин** — кнопка «рандом» из общего пула ников.
- **История** последних просмотренных скинов и **Избранное** —
  сохраняются в `localStorage`.
- **Конвертация формата** `64×32 → 64×64` одной кнопкой.
- **Скачивание** текущего скина в PNG.

### Пиксельный редактор

- **Рисование по текстуре** на canvas: карандаш, заливка (flood fill),
  пипетка и ластик; настраиваемый размер кисти.
- **Палитра** с базовыми цветами и списком недавних.
- **Сетка**, **отмена/повтор** (undo/redo) и очистка.
- **3D-рисование** — клик прямо по модели красит соответствующий тексель.
- **Скачивание** отредактированного скина.

### Анимации

- **12 поз** с плавными переходами: `idle`, `walk`, `run`, `wave`, `jump`,
  `dance`, `sneak`, `attack`, `cheer`, `sit`, `swim`, `spin`.
- **Кастомные кейфреймы** — выставьте позу слайдерами, запишите кадры
  и воспроизведите собственную анимацию.
- **Скорость и пауза** воспроизведения.
- **Экспорт** анимации в **GIF** и **WebM**.

### UI / UX

- **Вкладки** SKINS / VIEW / MOVE / EDIT / PLAY.
- **Горячие клавиши** — цифры `1–0` для анимаций, `R` — вращение,
  `Space` — пауза, `F` — полный экран, `H`/`J` — слои, `P` — pet-режим,
  `S` — скриншот, `?` — справка, `Esc` — закрыть.
- **Темы оформления** — neon, synth, matrix, ember.
- **Полноэкранный режим**, скрытие панели и **мобильная «шторка»**.
- **Онбординг-подсказки** и всплывающие уведомления (toasts).

### Социальные функции

- **Ссылка для шаринга** — состояние (скин, окружение, анимация) кодируется
  в URL `?skin=&env=&anim=` и восстанавливается при открытии.
- **Скриншот-карточка** — кадр в неоновой рамке с возможностью скачать.
- **Избранное** и **коллекции** для быстрого доступа.

### Геймификация

- **Достижения** — 12 ачивок с прогрессом в `localStorage`.
- **«Угадай игрока»** — мини-игра на распознавание скинов со счётом и сериями.
- **Творческий вызов** — случайная тема и таймер.
- **Pet-режим** — голова персонажа следит за курсором.

### Технические улучшения

- **PWA** — манифест, иконка и service worker; приложение работает офлайн.
- **Адаптивное качество** — `pixelRatio` подстраивается под FPS.
- **Пауза рендера** при скрытой вкладке для экономии ресурсов.
- **Ленивая загрузка** превью в галерее и обработка ошибок загрузки
  (автоматический фолбэк на запасной источник).
- **Модульная архитектура** — ES-модули и лёгкая шина событий.
- **Счётчик FPS** в углу и адаптивная вёрстка под широкий и узкий экран.
